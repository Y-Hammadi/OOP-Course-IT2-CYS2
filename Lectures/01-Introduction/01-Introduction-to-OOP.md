# Introduction to Object-Oriented Programming

### OOP — Course 01

- Understanding the OOP paradigm
- Core concepts and terminology
- Benefits and real-world applications

---

# 1. Programming Paradigms

- A programming paradigm is a style or approach to writing programs.
- Defines how code is organized and structured.
- Different paradigms provide different ways to solve problems.

### Common Programming Paradigms

- Procedural Programming
- Object-Oriented Programming
- Functional Programming
- Logic Programming

---

# 2. Procedural Programming

- Based on procedures and functions.
- Programs are divided into smaller functions.
- Instructions are executed step by step.
- Data and functions are generally handled separately.

### Key Characteristics

- Sequential execution
- Function-based organization
- Code reuse through functions

---

# 3. What is OOP?

- Object-Oriented Programming (OOP) is a programming paradigm.
- Organizes programs around objects.
- Objects represent real-world or conceptual entities.
- Combines data and behavior into a single unit.

### Main Idea

- Model software using objects that interact with each other.

---

# 4. What is an Object?

- An object is an instance of a class.
- Represents an entity in a program.
- Contains data and behavior.

### An Object Has:

- **State:** Data or attributes.
- **Behavior:** Actions or methods.
- **Identity:** A unique existence.

### Example: Car

- State: Color, Model, Speed.
- Behavior: Start, Stop, Accelerate.

---

# 5. Why Do We Need OOP?

- Managing complex software systems.
- Organizing large codebases.
- Reducing code duplication.
- Improving code maintainability.
- Supporting code reusability.
- Making software easier to extend.

---

# 6. Procedural vs Object-Oriented Programming

### Procedural Programming

- Focuses on functions and procedures.
- Data and functions are generally separate.
- Follows a step-by-step approach.
- Suitable for smaller and simpler programs.

### Object-Oriented Programming

- Focuses on objects and classes.
- Combines data and behavior.
- Models entities and their interactions.
- Suitable for complex and expandable systems.

---

# 7. Basic OOP Terminology

### Class
- A blueprint or template for creating objects.

### Object
- An instance of a class.

### Attributes
- Variables that represent an object's data.

### Methods
- Functions that define an object's behavior.

---

# 8. Class vs Object

### Class
- Defines the structure of an object.
- Specifies attributes and methods.
- Acts as a blueprint.

### Object
- Created from a class.
- Has its own state.
- Can perform the methods defined by its class.

### Example

- Class: Student
- Objects: Student1, Student2, Student3

---

# 9. The Four Pillars of OOP

Object-Oriented Programming is built around four fundamental concepts:

1. Encapsulation
2. Inheritance
3. Polymorphism
4. Abstraction

- These concepts help create organized, reusable, and maintainable software.

---

# 10. Encapsulation

- Bundling data and methods within a class.
- Controlling access to internal data.
- Protecting an object's internal state.

### Key Idea
- Keep data and related operations together.
- Provide controlled access to object data.

---

# 11. Inheritance

- Allows a class to inherit properties and methods from another class.
- Promotes code reuse.
- Establishes relationships between classes.

### Key Idea
- Create new classes based on existing classes.

### Example
- Parent Class: Animal
- Child Classes: Dog, Cat

---

# 12. Polymorphism

- Means "Many Forms".
- Allows the same interface to represent different behaviors.
- Enables objects to respond differently to the same operation.

### Key Idea
- One operation, different implementations.

### Example
- Dog → MakeSound() → Bark
- Cat → MakeSound() → Meow

---

# 13. Abstraction

- Hiding unnecessary implementation details.
- Exposing only essential features.
- Reducing complexity.

### Key Idea
- Focus on what an object does rather than how it does it.

### Example
- Driving a car without knowing how its engine works internally.
